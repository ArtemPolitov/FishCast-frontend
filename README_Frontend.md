# FishCast — Weather and Fish Bite Forecast

[Go to the app](https://fish-cast-frontend.vercel.app)

## About the project

FishCast is a web application that helps anglers check the weather forecast and estimate the likelihood of fish bites in various regions and fishing spots across Ukraine. The app supports user authorization, favorite locations, theme and language switching, as well as an interactive map.

## Technology stack

- **React**  
- **Next.js**  
- **TypeScript**  
- **Redux Toolkit + RTK Query**  
- **SCSS + CSS Modules**

## Main features

- Search for fishing spots near populated areas  
- Weather forecast and fish bite probability near a city or specific location  
- User authorization and saving favorites  
- Dark/light theme toggle  
- Responsive design  
- Interactive map with markers
